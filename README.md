# مشروع جوالة جامعة الريادة — نسخة تطوير قابلة للتسليم للمراجعة

واجهة عربية RTL مبنية بـ React + Vite، ومهيأة للربط بـ Supabase وVercel. تستعمل شعار الجامعة وصورًا من نطاق الجامعة الرسمي كمرجع بصري؛ يجب أخذ موافقة الجامعة على إعادة الاستخدام قبل الإطلاق الرسمي.

## الموجود في هذه النسخة
- موقع تعريفي متجاوب وهوية كحلي/ذهبي، مع رابط الموقع الرسمي.
- نموذج طلب انضمام يحفظ الطلبات في Supabase.
- دخول مسؤول عبر Supabase Auth وفحص صلاحية المسؤول من قاعدة البيانات.
- لوحة إدارة لطلبات الانضمام، والأنشطة (إنشاء/تعديل/حذف)، ومعرض الصور (رفع/حذف)، والأخبار، والإشعارات، وقائمة الأعضاء المعتمدين.
- مخطط قاعدة بيانات للفعاليات والمشاركين وساعات التطوع والشهادات ومحتوى الصفحات وسجل التدقيق.
- حماية RLS للبيانات الإدارية وسياسات Storage للصور.

## مهم قبل استخدام حقيقي
هذه حزمة مشروع جاهزة للتثبيت والربط والاختبار، وليست منشورة تلقائيًا وليست اعتمادًا رسميًا من الجامعة. الميزات الإدارية التي تحتاج إعدادات خارجية لن تعمل قبل تشغيل SQL وربط Supabase. لا توجد بيانات دخول افتراضية.

بعض الوظائف التي تتطلب عملًا إضافيًا قبل إطلاق رسمي: واجهة تحرير كل نصوص الصفحات، إدارة قوائم المشاركين من واجهة الأدمن، إنشاء حساب عضو آمن بعد الموافقة، إشعارات البريد/الهاتف، إصدار ملفات شهادات فعلية، وإكمال سجل التدقيق الآلي. جداولها الأساسية موجودة في SQL لكنها ليست كلها موصولة بواجهات هذه النسخة بعد. لا تعرض المشروع باعتباره مكتملًا نهائيًا قبل اختبار هذه الوظائف واعتماد الجامعة.

## 1. إعداد Supabase
1. أنشئ مشروعًا جديدًا في https://supabase.com/.
2. افتح SQL Editor > New query، وشغّل `supabase/schema.sql` كاملًا.
3. افتح Authentication > Users وأنشئ حساب المسؤول بنفسك بكلمة مرور قوية.
4. في SQL Editor، عيّن حسابك كمسؤول باستبدال البريد:
   ```sql
   update public.admin_profiles p
   set is_admin = true, role = 'super_admin'
   from auth.users u
   where p.user_id = u.id and u.email = 'YOUR_ADMIN_EMAIL';
   ```
5. من Project Settings > API انسخ Project URL والمفتاح العام `publishable` أو `anon` فقط.

## 2. تشغيل محلي
1. انسخ `.env.example` إلى `.env.local`.
2. أدخل القيم الحقيقية:
   ```env
   VITE_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
   VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_PUBLISHABLE_OR_ANON_KEY
   ```
   يجب أن ينتهي الرابط بـ `.supabase.co` فقط، بدون `/rest/v1/`.
3. في مجلد المشروع شغّل:
   ```bash
   npm install
   npm run dev
   ```
4. لفحص نسخة الإنتاج:
   ```bash
   npm run build
   npm run preview
   ```

## 3. النشر على Vercel
- ارفع محتويات المجلد إلى جذر مستودع GitHub.
- استورد المستودع في Vercel باختيار Vite.
- Build Command: `npm run build`، Output Directory: `dist`.
- أضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` إلى Environment Variables ثم أعد النشر.
- لا ترفع `.env.local` ولا أي `service_role` أو مفتاح سري.

## 4. اختبارات ما قبل التسليم
- إرسال طلب انضمام تجريبي والتحقق من ظهوره في لوحة الأدمن.
- التأكد أن زائرًا غير مسجل لا يستطيع قراءة الطلبات أو تغييرها.
- تجربة إنشاء نشاط وتعديله وحذفه.
- تجربة رفع صورة ضمن حدود الحجم والنوع ثم حذفها.
- تجربة نشر خبر وإشعار.
- اختبار الموقع على هاتف وشاشة كبيرة.
- مراجعة سياسات الخصوصية، وموافقة الجامعة على الشعار والصور والمحتوى.

## الهوية الرسمية
الموقع الرسمي: https://rst.edu.eg/?lang=ar
الشعار وصور الجامعة في الواجهة مستضافة على نطاق الجامعة الرسمي؛ روابط الصور الخارجية قد تتغير. الأفضل أن توفر الجامعة ملفات الهوية الرسمية المعتمدة وحقوق استخدامها قبل النشر العام.
